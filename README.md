# saving.github.io

这是一个个人使用的记账软件。该软件以 Github Page 的形似部署。

## 架构

1. 原则上只允许使用原生 HTML / CSS / JavaScript
2. 在万不得已的情况时，必须在我的授权下才允许引入三方库
3. 该网页只在手机端使用，不考虑其他平台的适配
   1. 因此，一般情况下不考虑悬浮窗类的设计，从视觉上建议采用新的页面
4. 可以拆分为多个 HTML，CSS， JavaScript 文件
5. URL确保只用一个即可，避免复杂的同步逻辑

## 需求

### 数据
1. 数据使用 JSON 存储于本地
2. 提供导出按钮，点击之后直接复制即可
   1. 导出支持导出配置和记账数据
3. 为了方便检索，可以按需分开存储数据。最终导出的时候合并即可

### 记账页

1. 提供金额，标签，付款方式和可选备注
2. 不考虑收入

### 设置页

1. 可配置标签，付款方式
2. 固定支出配置
   1. 支持配置周期性的支出，可配置 金额/时间/付款方式/标签
   2. 逻辑: 我们的部署方式采用 Github Page，没有后台。所以定期记账的逻辑非常简单。假设我们配置了每月 8 号交水电费。那么每次打开该网站，自动检查一下最近一次是否记录了该数据。如果没有就写入，写了就跳过

### 数据展示页

1. 支持按时间，标签，付款方式三种形式来展示

## 页面设计

1. 这是一个个人使用的项目而已，所以确保干净，简单，好看，轻松即可

## 已确认的初版约定

**核心目标：打开后尽快记上一笔。** 不为低频需求增加日常记账步骤。本节为后续确认，固定支出的补记方式以本节为准。

- 单入口页面，底部切换记账、明细、设置；原生实现，无需构建或第三方依赖。
- 金额为人民币，精确到分；时间默认当前时间，可修改。标签表示交通、餐饮、房租等支出方向，可多选；标签和付款方式全部平铺。
- 标签可不选，付款方式默认使用上次选择；备注选填，在明细中展示并可修改，随账目一同导出；保存后清空金额和备注，保留选项，方便连续记账。
- 明细默认本月，支持月份、标签、付款方式筛选；支持修改、删除。退款通过修改原账目处理。
- 固定支出支持每日、每周、每月（1—28 日）。打开网站时弹窗展示遗漏记录，勾选需要补齐的记录后确认；可直接关闭。未勾选的下次仍可补齐。
- 固定支出修改从当天生效，之前遗漏按原配置计算；删除规则停止当天及以后的支出，之前遗漏仍可补齐。删除已补账目不会使其重新待补。
- JSON 保存在 LocalStorage，导出包含配置和账目；暂不提供导入。保存失败保留输入，复制失败可手动复制。清理浏览器网站数据会清除账目。
- 删除标签或付款方式不影响历史账目；固定支出引用的选项需先从规则中调整，再删除。
- 设置页的标签、付款方式名称在离开输入框或按回车时自动保存，右侧小叉叉用于删除，不设单独的保存按钮。

## 使用与验证

将仓库根目录作为 GitHub Pages 发布目录即可，无构建步骤。资源使用相对路径。

本地预览：在根目录运行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000`。

逻辑测试：`node --test tests/core.test.js`。

手机浏览器验证：`node --test tests/browser.test.js`（使用已安装的 Chrome 或 Edge，也可用 `CHROME_PATH` 指定；无浏览器时跳过）。使用独立临时浏览器，不读取个人浏览数据。

核心目标也记录在根目录 AGENTS.md，供后续在此仓库工作的助手读取。
